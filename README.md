# 🕷️ Retrolens - Venom Symbiote Edition

Aplikasi filter kamera interaktif dan live streaming broadcast overlay berbekal **AI Hand-Tracking** (MediaPipe & OpenCV). Dilengkapi dengan tema **Venom Symbiote**, 4-Point Filter Portal, Air-Snap Ultra-HD Photo Capture, Video Air-Clip Recorder, Telemetry AI Diagnostics, Dynamic Hand Zooming & Lock, serta integrasi **OBS Virtual Camera** untuk streaming di Zoom, Google Meet, OBS, Discord, dan YouTube.

---

## 🌟 Fitur Utama

- **🕷️ 24 Visual Shader Filters**: Koleksi visual shader terlengkap meliputi Venom Symbiote, Spider-Man Comic, Split-Screen Combo, Cyberpunk Wireframe, Plasma Burst, Night Vision, Hologram, Thermal Scan, Sketch Noir, Emboss, dan masih banyak lagi.
- **📊 Filter Counter Badge**: Badge di pojok kanan atas menampilkan nama filter aktif dan posisi `[X/24]` secara real-time.
- **👉 Finger Gun Quick-Switch**: Gestur Finger Gun (👉) untuk quick-switch ke filter terakhir yang digunakan!
- **🔢 Direct Theme Shortcuts (Keys 0-9)**: Beralih instan ke tema unggulan.
- **🤚 8 Gesture Detectors**: Peace ✌️, OK 👌, Claw 🖐️, Fist ✊, Metal 🤟, Pinch 🤏, Navigator (Jempol+Manis), dan **Finger Gun** (👉).
- **📊 Real-time AI Telemetry Diagnostics (Key `d`)**: Menampilkan telemetry card mengambang.
- **💥 Dual-Hand Ultimate Combo (🤟 🤟)**: Burst `MULTIVERSE-GLITCH` + alien roar SFX!
- **⚡ Spider-Sense Warning Arc**: Dekatkan kedua telunjuk tangan.
- **🌀 Symbiote Pinch Energy Link**: Garis energi 1px alpha 0.35.
- **🎬 Video Air-Clip Recorder**: 5 detik (✊ / `r`).
- **📸 Air-Snap Photo Capture**: (✌️ / `s`).
- **📖 Interactive Glassmorphism Help Guide**: (`h`).
- **🔍 Dynamic Hand Zoom & Lock**: (🤏 / 👌).
- **🎥 OBS Virtual Camera Output**.
- **🎧 8 Async Sci-Fi Audio Synthesizers**.
- **🧼 100% Clean & Stream-Ready Visuals**.

## 💻 Persyaratan Sistem

- Python 3.8 atau lebih baru
- Windows OS (Support DirectShow & OBS Virtual Camera)
- Webcam (Disarankan 1080p @ 30/60 FPS)

## 🚀 Cara Install dan Menjalankan

```powershell
cd python-handtrack
.\venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
